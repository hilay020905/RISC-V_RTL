# RISC-V-RTL

A consolidated collection of RISC-V processor implementations and extensions developed using Verilog/SystemVerilog.

## Projects

| Project | Description | Directory |
|---|---|---|
| **RV32I** | RISC-V 32-bit base integer instruction set implementation | [RV32I](./RV32I/) |
| **RV32IMZicsr** | RISC-V 32-bit implementation with M extension and Zicsr support | [RV32IMZicsr](./RV32IMZicsr/) |
| **RVV** | RISC-V Vector Extension implementation (RV32IV) | [RV32IV](./RV32IV/) |
